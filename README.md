# Marvel-Hero-Finder


A simple web application to search for Marvel characters using the **Marvel API**. Users can search characters by name and view their image, description, and other details.

---

## **Features**

- Search for Marvel characters in real-time.  
- Autocomplete suggestions while typing character names.  
- Displays character image, name, and description.  
- Interactive UI with hover effects on images.  
- Responsive layout for different screen sizes.

---

## **Technologies & Tools Used**

- **Languages:** HTML, CSS, JavaScript  
- **API:** Marvel Developer API  
- **Libraries/Frameworks:** None (vanilla JS)  
- **Tools:** Browser console, GitHub, VS Code
